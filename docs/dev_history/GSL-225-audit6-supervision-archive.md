# GSL-225 — След супервизии переживает самоусечение: трекаемый архив heartbeat и леджера

## What was done

Вся эмпирика аудита 2026-07-24 покрывала четыре дня, потому что след супервизии жил вне git и
самоусекался: heartbeat режется до 200 строк собственным писателем (снипет суверенного скилла
оркестратора), watchdog-леджер лежит рядом, оба под .gitignore, и один `git clean -fdx` стирал всю
доказательную базу (находка 60). Теперь каждый проход хроникёра — который и так читает эти файлы —
дописывает невиданные строки в ТРЕКАЕМЫЕ архивы `docs/lab/supervision/heartbeat.jsonl` и
`docs/lab/supervision/watchdog-ledger.jsonl`. Живые runtime-файлы остаются ignored (контракт их
писателей суверенен и не тронут); история попадает в git через архив. Шаг выполняется первым в
проходе — до всего, что может упасть, — потому что живые файлы усекаются по чужим часам. На живых
данных первый же проход захватил 200 строк пульса; леджер сторожа на этой машине пуст честно
(сторож ни разу не тикал — архиватор говорит это, не молчит).

## Problems solved

- **Идемпотентность и порядок.** Дедуп по точной строке (пульс = JSON-строка с посекундным ts и
  циклом — одинаковая строка означает тот же пульс); порядок — старый архив, затем новые строки в
  порядке живого файла; запись атомарная через lab_write (temp+rename), dry-run не пишет ничего.
- **Развилка «архив или снятие ignore с живых файлов»** оформлена q-2026-07-28-004 с применённым
  дефолтом: трекать самоусекающийся живой файл = вечно грязное дерево и всё равно потеря истории
  при усечении; суверенный скилл прямо велит его gitignore'ить.

## Problems remaining

- Окно неуязвимости зависит от каденса хроникёра: 200 строк при пульсе каждые 5-10 минут — от 16
  часов покрытия; хроникёр ходит многократно чаще (каждый гейт и граница цикла), так что на
  практике потерь нет, но машина, где хроникёр не запускался более 16 часов при живом оркестраторе,
  потеряет старейшие пульсы. Настоящее лечение — писатель, архивирующий перед усечением, а писатель
  суверенен; зафиксировано здесь.
- Ротация архива не введена (файл растёт вечно): ~130 байт на пульс — годы до заметного размера;
  ротацию решать тогда, не сейчас.

## Pitfalls & workarounds

- Архив пишется и при degraded-проходе (шаг стоит до загрузок), но НЕ при --dry-run (lab_write
  сам не пишет). В отчёте прохода — блок supervision_archive (сколько строк дописано, сколько
  всего; отсутствие живого файла — «нечего архивировать», не ошибка).
- Скрытые атомарные temp'ы lab-write в docs/lab/supervision/ уже покрыты паттерном
  `docs/lab/**/.*.tmp` — git их не увидит.

## What didn't make it

- Правка писателя heartbeat (суверенный скилл) и watchdog.sh — запрещено; архиватор снаружи.
- Снятие .gitignore с живых runtime-файлов — отвергнуто дефолтом развилки (см. выше); в .gitignore
  добавлен комментарий, куда след теперь попадает.
