# GSL-222 — Метрика автономности 1 − asks/shipped за скользящие 7 дней

## What was done

Рядом с RUNWAY появилась вторая метрика автономности — та, что могла дать число уже сегодня из
данных на диске (находка 91, заимствование 5dive): `1 − asks/shipped` за скользящие 7 дней.
asks — вопросы, которые флот задал владельцу (BLOCKER/DECISION/CLARIFY; FYI ничего не спрашивает),
из очереди и архива с дедупом по id. shipped — уникальные ключи задач, замеченные в Done внутри
окна по трекерным событиям. Блок целиком лежит в `status.json` (`autonomy`) и печатается в разделе
5 утреннего дайджеста — всегда ВМЕСТЕ с честной рамкой «чего это число не утверждает» (пять
пунктов), потому что одиночное число про автономность — ровно то, что цитируют без оговорок.

## Problems solved

- **Ноль в знаменателе.** shipped=0 не делает метрику ни 1.0, ни 0.0 — она «unmeasured» с причиной
  и указанием, что её наполняет (poll-fill --jira-json, GSL-223). На живых данных сейчас честно:
  asks=13, shipped=0, value=null — трекерная лента пуста 11 дней, и метрика говорит об этом сама.
- **Дубли Done.** Один ключ, дважды замеченный в Done в окне, считается один раз (set по ключу);
  день берётся из occurred_at (когда случилось), с откатом на ts (когда узнали).

## Problems remaining

- Число оживёт только после GSL-223 (подкачка JQL-выгрузки в poll-fill) — следующая задача эпика.
- Отрицательное значение (asks > shipped) печатается сырым, не клампится — это осознанно (кламп
  спрятал бы именно неделю, которая пошла не так); заявлено в рамке.

## Pitfalls & workarounds

- Очередь одна не годится для asks: apply_retention архивирует закрытые вопросы в archive.jsonl, а
  --compact-queue может выкинуть их из queue.jsonl — архив читается сырым (это цельный
  атомарно-перезаписываемый файл СВЁРНУТЫХ записей; запрет «не читать сырьём» касается только
  queue.jsonl с его патчами).
- Рамка не разделяема с числом по конструкции: и в status.json, и в дайджесте они идут одним блоком.

## What didn't make it

- Экран в веб-UI — задача его не просит (status.json + дайджест); бандл не расширялся.
- shipped по закрытым GH-зеркалам или коммитам с ключами — второй источник дал бы двойной счёт и
  спрятал бы главный дефект (мёртвую трекерную ленту); единственный источник назван в sources, его
  слепота — в рамке.
