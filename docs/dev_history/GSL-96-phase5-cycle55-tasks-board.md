## Part 1 — простыми словами

Экран Tasks стал доской, где **строка = задача, ключ = Jira-ключ**, и каждый идентификатор на
странице — либо ссылка, которая открывается, либо честно названное отсутствие. Третьего состояния
нет: `GSL-96` ведёт в Jira, `#109` — в GitHub issue, коммит — в diff, `dev_history` — в файл истории.
Сверху задачи свёрнуты по эпикам: эпик показывает свой PR и его состояние, а раскрыв его, видно, из
каких задач он состоит.

**Главное, чего экран НЕ делает: он не выводит «Done» из наличия коммита.** 92 из 101 строки стоят
`unknown` — потому что статусы приходят из Jira, а у лаборатории нет ключей Jira (C1) и poll кормится
руками. Соблазн закрыть эти 92 дырки очевиден: коммит же есть, задача же наверняка сделана. Но коммит
свидетельствует, что код приземлился, — и ничего не говорит о том, что думает трекер, а трекер —
единственное, о чём колонка «status» вообще заявляет. Доска, которая подставила бы сюда правдоподобное
«Done», врала бы ровно в той колонке, по которой владелец решает, можно ли идти спать.

**Второе: у эпика GSL-90 нет PR — и страница так и говорит.** Ветка запушена, PR не открыт (GH #103 —
это epic *issue*, а не pull request). Тут была самая опасная ловушка задачи: issue и PR живут в одном
пространстве номеров, поэтому «одолжить» номер issue под видом PR — это не битая ссылка, которая
честно ляжет в 404. Она **откроется**, на настоящей странице, которая не есть то, на что кликнули.
Такую ссылку владелец проверит один раз, окажется не там и перестанет верить колонке, которая была
права.

**Третье: возраст статуса продолжает стареть, пока страница открыта.** Рядом со статусом написано,
сколько ему часов, и это число пересчитывается **в момент открытия страницы**, а не остаётся тем,
которое испеклось на сборке. Иначе страница, собранная в 23:00, в 04:00 занижала бы собственную
протухлость ровно на то время, которое владелец спал, — снова ложь в успокаивающую сторону, ту
единственную, которая имеет значение.

Из неожиданного: **утверждение «маппинга Jira→GitHub issue не существует» оказалось неверным.**
Предыдущий цикл вывел его из того, что маппинга нет **на диске** (он живёт в прозе handoff'ов), и
колонку GH просто не построил. Но сборка уже ходит в GitHub за pull request'ами, а наши же соглашения
кладут ключ **в заголовок issue** (`GSL-101: [Docs] …`). Маппинг машиночитаем — он просто не файл.
Колонка построена, и там, где GitHub не ответил, она пуста **с объяснением**, а не с догадкой.

### Членство эпика читается из топологии, а не из прозы

Соглашения доставки делают это точным: **один branch на эпик** (`<EPIC-KEY>-<slug>`), **один коммит на
задачу** (subject начинается с ключа), **regular merge, никогда squash**. Отсюда:

```
смёрдженный эпик  →  второй родитель merge-коммита И ЕСТЬ история эпика:  mc^1..mc^2
эпик в полёте     →  его ветка просто ещё не в стволе:                    main..<branch>
```

В теле PR есть чек-лист задач, и он был бы источником попроще. Он неверный: это **проза**, написанная
руками в момент **открытия** PR. Rollup, построенный на ней, докладывает эпик, который мы *собирались*
отгрузить. Топология докладывает тот, который отгрузили, — и когда эти двое расходятся, владельцу в
03:00 нужен второй. Реальность: 13 эпиков через merge-commit, 1 (GSL-90) через ветку, 0 неизвестных.

### Схема — двусторонний контракт, бампалась намеренно

`render/3` → `render/4` в трёх местах одновременно (`chronicler.py`, `render.tsx`, `smoke.sh`),
плюс литеральный тип в `types.ts`. Рендерер бросает на незнакомой схеме — это и есть причина, по
которой бамп безопасен: старая страница не может быть собрана из нового бандла молча.

**Это отступление от брифа цикла** («chronicler.py не трогать»). Приёмка F5-S3 живёт в описании Jira, а
не в брифе, и требует GH-ссылок и epic→PR rollup — ни то, ни другое не выводится в рендерере из
`render/3`. Альтернативой было выдумать ссылки во view, что задача запрещает прямым текстом. Записано
как DECISION `q-2026-07-13-003` (обратимость high); C5 — денилист **слов** (`tmux|spawn|Agent tool|
teammate`), а не запрет на файл, и слова не тронуты (греп зелёный).

### `GOSLEEP_GH_JSON` — точка инъекции, не запасной путь

Лаборатория не держит кредов (C1) и обязана собираться на машине без `gh` и без сети. Но тест, который
умеет видеть **только деградировавший** путь, никогда не видит колонку, которую охраняет, — а эта
колонка есть половина F5-S3. Поэтому файл, по форме ровно такой, какой отдаёт `gh`
(`{"prs": […], "issues": […]}`), используется **вместо** сетевого вызова. Нечитаемый файл деградирует
**с логом**, а не притворяется, что GitHub промолчал.

### Тесты, которые нельзя пройти на сломанном коде

Фикстура — **свой** git-репозиторий (`$WORK/f5s3`), не chronicler'ов: у соседа есть тест, читающий
дайджест, и чужие данные молча переписали бы его арифметику (на этом обжёгся impl-ui-2).

```
main ──●───────────────────●(merge #999: GSL-700-alpha)──●
        \                 /                               \
         ●GSL-701 ●GSL-702                                 ●GSL-801  (GSL-800-beta, НЕ смёржена)
```

`GSL-701` опрошен и Done. **`GSL-702` имеет коммит и не имеет опроса** — строка, на которой держится
вся доска. У эпика `GSL-800` есть GH issue #800 и **нет PR** — ровно та ловушка, в которой можно
одолжить номер.

**Проверено мутацией — каждая ломает ровно свой тест (191/192), остальные остаются зелёными:**

| мутация | что покраснело |
|---|---|
| заморозить `paint()` в `tickAges` | ⭐ «возраст продолжает стареть» (build-time тест при этом остался зелёным → позитивный контроль настоящий) |
| `status ?? (commits.length ? "Done" : …)` | ⭐ «коммит — не статус Jira» (`STATUS=Done\|HAS_COMMIT=yes`) |
| одолжить issue-номер эпика под видом PR | «эпик без PR так и говорит» (`SAYS_NONE=no`) |
| вывести `issues/702` из номера ключа | «ключ, которого нет в зеркале, получает прочерк, а не догадку» |

Плюс механические ассерты вместо теней: `id="task-GSL-N"` ↔ `href="#task-GSL-N"` (0 висячих якорей из
82 на реальной странице), `data-pr`, `data-epic`, `data-membership`, `data-age-ts`. ⭐-тест возраста
исполняет **клиентский бандл самой страницы** в node со стаб-DOM и подменённым `Date`: мокается только
окружение, исполняется ровно тот JS, который получит браузер владельца.
