# GSL-214 — Минимальный circuit breaker: строка в STATE плюс пункт в HEARTBEAT_OK

Эпик GSL-178 (аудит 2026-07-24, эпик 5 «Супервизия»). Смена 74, исполнитель impl-178.

## What was done

Circuit breaker перестал быть только прозой в скилле (F11: предписанная строка `breaker=` не
появилась в STATE ни разу за ~104 цикла, breaker.\* — 0 из 1933 событий). Реализован минимум по
оценке красной команды, ровно в две половины. Половина оркестратора: одна строка `breaker=` в
ORCHESTRATION-STATE.md, обновляемая на границе цикла, — точный текст и якорь подготовлены
эрратой `GSL-178-errata-orchestration-state.md` (Вставка 2; STATE суверенен, вставляет
оркестратор). Механическая половина: `tools/lab/breaker-check.sh` — пункт HEARTBEAT_OK, который
эту строку ЧИТАЕТ: существует · парсится (state, since, четыре счётчика со знаменателями) ·
дисциплина держится (счётчик на/за порогом при CLOSED — названо вслух). Переходы состояния
зеркалируются в docs/lab/events/ через lab-emit по фронту (memo-файл): CLOSED→OPEN даёт
breaker.opened один раз, OPEN→CLOSED — breaker.closed; повторные прогоны не дублируют. Коды
выхода: 0 зелёный; 1 нет строки/битая/дисциплина нарушена; 2 = OPEN (сознательный СТОП,
отличимый от ошибки формата). Текст пункта HEARTBEAT_OK — Замена 5 скилловой эрраты.

## Problems solved

- **«Числится сделанным, а его нет» → честный красный сегодня**: на живом STATE breaker-check
  даёт rc 1 «NO breaker= line» с указателем на эррату — F11 виден каждому HEARTBEAT_OK, а не
  раз в аудит. Зелёным станет в момент применения эрраты оркестратором.
- **Приёмка «breaker.opened от синтетического прогона видно в docs/lab/events/»** — исполнена
  на фикстурном lab-каталоге тем же кодом, что работает в бою (q-2026-07-28-008, дефолт:
  урок q-005 запрещает тестовые эмиссии в боевой лог; боевой breaker.opened появится при
  первом реальном OPEN).
- **Событие по фронту, не по уровню**: memo-файл держит последнее виденное состояние — тик
  каждые 3 минуты при OPEN не превращается в 480 событий за сутки.

## Problems remaining

- Счётчики по-прежнему СЧИТАЕТ оркестратор (дисциплина скилла) — механика только валидирует и
  ловит «насчитал до порога и не открыл». Полностью механический подсчёт сигналов (next_same по
  диффу STATE, no_pr по gh) — сознательно за объёмом минимума; наблюдательный прогон покажет,
  нужен ли он.
- Строки в STATE ещё нет (суверенитет) — до применения эрраты пункт красный, и это правильно.

## Pitfalls & workarounds

- lab-emit пишет JSON С ПРОБЕЛАМИ (`"type": "..."`), а мой первый grep искал слитно — тест
  «событие не эмитится» на самом деле означал «паттерн не матчится»; заодно `grep -c | tr` под
  `set -euo pipefail` убивал харнесс при нуле совпадений (rc 1 в pipefail). Обе граблины
  закрыты хелпером bev_count с `|| true`.
- Регэксп парсера принимает хвост после четырёх счётчиков (cooldown/next_probe и будущие
  поля) — формат расширяем без ломки читателя.

## What didn't make it

- Автозапись строки breaker= механикой — STATE пишет только оркестратор; эррата и есть канал.
- Валидация возраста since/next_probe — просроченные часы уже ловит fast-path чек-лист скилла
  (раздел «no expired clocks»); дублировать не стал.
