# Dev-history assets

Папки называются по ключу **задачи**, снявшей кадры: `assets/<TASK-KEY>/` (не эпика).
Именование листов: `<страница>-<ширина>-<тема>.png`; кадры — строго viewport, обе темы.
Нормативное описание конвенции: раздел «Assets — скриншоты и бинарные приложения»
в [`../README.md`](../README.md) (GSL-142). Ассеты верификационных ранов живут отдельно:
`docs/reports/verifications/<EPIC-KEY>/runs/NN/` — сюда не дублируются.
