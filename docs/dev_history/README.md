# Dev history — index

One file per Jira Task, written right after the task's commit lands. Part 1 of each file is the
plain-language story (what was done, what hurt, where the bodies are buried); Part 2 is the short
technical reference. See `CLAUDE.md` for the convention.

Legacy pre-GSL history (the TLM / tasty-lunch era, numbered `00`–`10`) lives in `docs/dev-history/`
(hyphen) and is kept as imported history — new entries go here.

## Assets — скриншоты и бинарные приложения (конвенция, GSL-142)

Скриншоты и прочие бинарные ассеты dev-history лежат в **`docs/dev_history/assets/<TASK-KEY>/`** —
по ключу **задачи**, которая их произвела, не эпика. История пишется per-task (один файл = одна
задача = один коммит), и ассеты ложатся рядом со своим файлом: читатель `GSL-NNN-….md` находит
подтверждения в `assets/GSL-NNN/`, не зная ключа эпика. Так фактически сложился весь каталог:
`GSL-100/`, `GSL-109/`, `GSL-133/`, `GSL-134/`, `GSL-135/`, `GSL-138/`.

**Именование листов** — как в `GSL-138/`: `<страница>-<ширина>-<тема>.png` (например
`cost-1280-dark.png`, `index-390-light.png`). Для доказательных кадров «до/после» допустимы
говорящие имена (`mono-spill-before.png` в `GSL-100/`) — лишь бы имя называло, что на кадре.
Скриншоты-подтверждения UI-правок — строго viewport-кадры (1280×800 и 390×844, обе темы), не
fullPage-«полотна»; перед затвором проверяется computed background обеих тем.

**Разграничение с верификационными ранами.** Приёмочные ассеты ранов живут внутри рана —
`docs/reports/verifications/<EPIC-KEY>/runs/NN/` (см. README там) — и **не дублируются** сюда.
Ран может осознанно скопировать листы К СЕБЕ ради самодостаточности отчёта (так сделал run 01);
обратного потока нет.

**Историческая сноска.** Тикет GSL-138 обещал складывать приёмочные скриншоты в
`assets/GSL-111/` (по ключу редизайн-эпика); фактически они легли в `assets/GSL-138/` — по ключу
приёмочной задачи, по прямому брифу оркестратора. Расхождение разрешено в пользу per-task
конвенции, она и является нормой: **папка называется по задаче, снявшей кадры**. Следующий агент
не должен искать ассеты по ключу эпика.
