# GSL-2 — Import orchestration harness v0

## What was done

The whole Orchestration Harness landed in version control as the project's first version: the
`skill/` source of the `orchestrating-delivery-agents` skill, the 20-scenario behavioral eval
suite with its runner and scorecards, the HTML knowledge base under `docs/report/`, the design and
cost-analysis docs, the legacy dev-history, the handoff, and `install.sh`. Before this commit the
project lived only on disk — nothing was in git at all.

## Problems solved

The local `skill/` copy was three days behind the global one at `~/.claude/skills/`, which had
been hardened by a Fable 5 audit (richer ORCHESTRATION-STATE.md structure, a model-economy
section, worker context calibration, a human-first handoff skeleton). A diff audit confirmed the
global version was strictly additive — nothing local-only would be lost — so we reverse-synced
global → local first, and only then imported. The repo's source of truth now matches the active
global skill byte-for-byte.

## Problems remaining

- Generators and the eval runner still carry absolute paths from the pre-move location
  (`.../tasty-lunch/docs/orchestration-harness/`) — tracked as GSL-4.
- The last eval run left 8 of 20 scenarios in FAIL/REVIEW; the gap fixes were drafted as
  TLM-71..TLM-74 in the old tracker and have not yet been ported into the GSL backlog.

## Pitfalls & workarounds

- `install.sh` syncs **local → global** with `rsync --delete`. Running it while `skill/` is stale
  silently wipes improvements made directly to the global copy. Rule: if the global skill changed
  first, reverse-sync and commit before ever running `install.sh`.
- Report pages must use the fixed-height `.chart-wrap` pattern — unbounded Chart.js canvases froze
  the page once already.
- `docs/report/study.html` and `subagents.html` are generated by the `build-*.py` scripts; edit
  the generator, never the HTML.

## What didn't make it

- Git history from the tasty-lunch era — the owner moved the directory by hand, so the project
  starts its history here. The old story is preserved narratively in `docs/dev-history/00`–`10`.
- No eval re-run for this task: the suite is expensive (~1026 agents for a full run) and the
  stale-path debt (GSL-4) blocks the runner anyway.
