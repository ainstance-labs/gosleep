# GSL-170 — мандат владельца заехал в git ровно тем же файлом

## Что произошло

Проект существует ради одного документа. `docs/prompts/2-deep-orchestrating-research.md` — это
надиктованный владельцем текст, из которого выросло всё: оркестратор, лаборатория, автономность,
мобильный доступ, веб-интерфейс. Против него шёл глобальный аудит системы 2026-07-24 — семь
экспертов сверяли построенное с тем, что здесь заказано.

Этот файл никогда не был в git. Не «устарела версия» и не «отстала ветка» — история пуста, файл
всё время лежал в рабочем дереве как untracked. Соседний `1-run-fresh-agent.md` закоммичен, а
второй — нет; похоже, его просто забыли добавить, когда он появился 7 июля.

Любая чистка дерева, переключение ветки с `-f`, `git clean` или новая сессия на свежем клоне —
и первоисточник исчезает без следа. Восстановить его нельзя ниоткуда: это надиктованная речь
владельца, а не производный артефакт.

Теперь он в истории.

## Какую проблему пришлось решать аккуратно

`docs/prompts/` — суверенная папка. Её содержимое агентам редактировать запрещено: это голос
владельца, и любая «улучшающая» правка формулировки уничтожает свидетельство того, что было
заказано на самом деле.

Коммит — не редактирование. Содержимое не меняется ни на байт, меняется только то, знает ли git
о существовании файла. Но чтобы это было не обещанием, а фактом, копирование сделано `cp -p`
(сохраняет время и права), а совпадение проверено дважды и разными способами: `shasum -a 256` с
обеих сторон и `cmp` побайтово.

```
43300cdfdde1d1049f31a2559e1e2d8a92e220d705023d6a2027992fb350aae6  (основное дерево)
43300cdfdde1d1049f31a2559e1e2d8a92e220d705023d6a2027992fb350aae6  (worktree)
```

Файл не открывался редактором вообще — только на чтение, чтобы описать его в этой истории.

## Ловушка, из-за которой работа шла в отдельном дереве

В основном рабочем дереве в этот момент читали файлы два других агента смены 73 — синтез-архитектор
и красная команда. Переключение веток или коммит под ними испортил бы им работу на середине.

Поэтому весь эпик собран в отдельном git worktree (`../gosleep-audit-preserve`, ветка
`GSL-169-audit-preserve`), а исходники читались из основного дерева и копировались внутрь. В
основном дереве не выполнено ни одной изменяющей команды — только чтение и `git worktree add`.
Списки `git status --porcelain` в основном дереве до и после работы сверены и совпадают.

## Что проверено попутно

Соседи по `docs/prompts/` пересмотрены на тот же дефект: файлов там два, `1-run-fresh-agent.md`
уже в git, других untracked нет. Папка закрыта целиком.

## Что осталось

Ничего по этой задаче. Файл в истории, содержимое неприкосновенно.

Стоит помнить более общий урок: **untracked-файл в суверенной папке — это молчаливый дефект**.
Он не ломает ни один прогон, не роняет тест, не всплывает в статусе как ошибка — он просто есть,
пока однажды его не станет. Тот же дефект нашёлся в этом же эпике ещё в двух местах (GSL-171 —
доказательная база аудита, GSL-172 — архив вопросов и дайджест).

## Техническая справка

**Файл:** `docs/prompts/2-deep-orchestrating-research.md`, 13 743 байта, mtime 2026-07-07 22:23.

**Что сделано:**
```
cp -p <main>/docs/prompts/2-deep-orchestrating-research.md <worktree>/docs/prompts/
shasum -a 256 <обе стороны>   # совпало
cmp <обе стороны>             # тишина = идентично
git add docs/prompts/2-deep-orchestrating-research.md   # явный путь, без -A
```

**Содержание мандата (для будущего читателя, коротко):** заказ на глубокое исследование двух
оркестраторов (autosk, warren) с отчётом-дашбордом в `docs/reports`; проблема «оркестратора некому
оркестрировать сверху» (tmux/agent-teams дают один уровень вложенности); вопрос о `claude -p` и
работе по подписке; автономность с буфером накопленных вопросов вместо остановки на каждом; идея
лаборатории с автоматическими handoff / dev history / отчётами; UI с индикаторами автономности и
окном вопросов; loop engineering; мобильная оркестрация.

**Приёмка:** SHA-256 `43300cdf…50aae6` идентичен до и после; `cmp` без расхождений; после коммита
`git status --porcelain` в worktree по этому пути чист.

**Границы:** файл не редактировался; `docs/prompts/` остаётся суверенной; коммит добавляет только
этот один путь.
