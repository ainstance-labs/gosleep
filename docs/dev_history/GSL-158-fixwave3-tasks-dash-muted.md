## Часть 1 — человеческим языком

### Что сделано

Спека 6.5: заполнитель отсутствия красится `--muted`, чтобы пустота не выглядела данными.
Cost и Library несут эту конвенцию общим глифом `span.muted` («The absence glyph, muted
(spec 6.5)»). На Tasks board тот же смысловой глиф — «—» в колонке gh для ключа, которого нет в
ПРОЧИТАННОМ зеркале, — носил класс `dim` (#5a5b5d вместо #68696b): одно явление, два цвета на
соседних экранах. Фикс — `class="muted"` с несущим комментарием; title-тултип и сам символ не
менялись.

### Решённые проблемы

- Рассмотрен вариант вынести общий `const dash` как в cost/library — отвергнут: здесь глиф несёт
  title («no GitHub issue mirrors this key»), это не голый заполнитель ячейки, а заявленное
  отсутствие с причиной; общий глиф без title обеднил бы сообщение.

### Оставшиеся проблемы

- Нет.

### Подводные камни

- Не перепутать роли: `dim` на Tasks легитимно живёт на других элементах (ключи эпика без строки,
  «no PR»-ячейка). Менялся только глиф отсутствия с title зеркала — грепы держат класс и title
  вместе, чтобы не зацепить чужое.

### Что не вошло

- Пересборка закоммиченных derived-страниц — последним коммитом волны (норма docs/lab/README.md).
