## Что сделано

Фидбек владельца по отчёту GSL-138 run 01: (а) в отчёте не видно самого дизайна;
(б) full-page «полотна» — недопустимый формат скриншотов. Ответ — папка
`docs/reports/verifications/GSL-138/runs/01/design/`:

- **`design/pages/`** — замороженный снапшот всех 7 страниц `docs/lab/site/*.html` на момент
  рана 01 (`main @ fed234e`). Страницы полностью самодостаточны (инлайновые CSS/JS, без внешних
  ресурсов — проверено grep'ом и живым рендером), снапшот открывается из `file://` изолированно.
  Исходники `docs/lab/site/` не тронуты.
- **`design/index.html`** (EN) + **`design/ru/index.html`** (RU) — обзор дизайна в эстетике
  отчёта (переиспользованы `../assets/styles.css` и `lightbox.js`, та же схема билингвальности —
  RU-сосед + переключатель в шапке): палитра обеих тем живыми свотчами с hex (17×2, статусные
  цвета — тройками ink/soft/border), типографическая шкала (7 ступеней, база 13px, максимум веса
  500), шкалы отступов и радиусов, ключевые компоненты живым HTML в двух принудительно-темных
  панелях (табы, баннер свежести FRESH/STALE, статус-теги, таблица, KPI); карточка на каждую из
  7 страниц: описание + 4 кадра (1280/390 × light/dark) в лайтбоксе + кнопки «Open snapshot» /
  «Open live page»; секция про мобильную md-проекцию (`docs/lab/mobile/README.md`, GSL-137).
- **`design/assets/`** — 28 строго viewport-кадров (1280×800 и 390×844, DPR 1, никаких
  fullPage), сняты живым chromium с самого снапшота через `file://`.
- Точечные правки отчёта: кнопка **«Design showcase» / «Обзор дизайна»** в шапках
  `runs/01/index.html` и `runs/01/ru/index.html`. Больше в отчёте ничего не менялось
  (переделка галереи-полотен — run 02).

## Грабли

- `mcp__chrome-devtools__emulate` **сбрасывает неуказанные оверрайды**: вызов только с
  `colorScheme` сбросил viewport (кадры вышли 1000×1688), вызов только с `viewport` сбросил тему
  (390-dark вышли светлыми). Лечение: всегда передавать оба параметра одним вызовом; все 21
  бракованный кадр переснят, размеры и темы перепроверены пофайлово (`sips` + визуально).
- localStorage `arc-theme` у `file://`-origin общий на все страницы отчёта: ручной оверрайд
  побеждает эмулированный `prefers-color-scheme` — это корректное поведение страницы, а не баг;
  тёмная тема проверена кликом по тумблеру, значение возвращено как было.
- Путь «Open live page» из `design/` — **6** уровней вверх (`../../../../../../lab/site/`), из
  `design/ru/` — 7; в постановке было 5 (скопировано из уровня отчёта). Все 49+49 относительных
  ссылок обеих версий проверены скриптом на существование файлов.
