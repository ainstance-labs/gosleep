# GSL-244 — Отчёт аудита наконец лёг в репозиторий: две страницы, 99 находок

## Что произошло

Глобальный аудит системы оркестрации закончился 24 июля 2026 года. Десять агентов на Opus 5:
шесть независимых аудиторов по своим зонам, три красные команды, перепроверявшие их находки, и
ведущий архитектор, сводивший всё в корневые причины. Результат — 99 находок, восемь предложенных
эпиков, восемь вопросов владельцу, сведённые в дашборд на двух языках.

И этот дашборд лежал untracked.

То есть главный продукт всей работы — то, ради чего аудит затевался, — не был в контроле версий.
Ровно та же болезнь, которую предыдущий эпик (GSL-169) лечил для доказательной базы, только
на этот раз у самого отчёта.

Теперь он в git: `docs/reports/system-audit-2026-07-24/`, 22 файла, 1,5 МБ.

## Что именно закоммичено

```
index.html      404 КБ   английская версия, 99 находок с фасетным фильтром
ru/index.html   529 КБ   русская версия, те же 99 находок и те же якоря
assets/         43 КБ    styles.css и app.js — обе страницы делят ОДНИ файлы
build/          520 КБ   генератор и всё, из чего страницы собираются
```

## Почему `build/` тоже поехал в git

Первый инстинкт — не коммитить генератор: страницы же готовы, зачем исходники.

Инстинкт неверный, и вот почему. `index.html` — это 404 КБ сгенерированной разметки. Любая
будущая правка находки (а правки будут: часть чисел аудита уже исправлена красными командами)
в такой файл вносится либо руками по всему документу в двух языках сразу, либо генератором.
Руками — невоспроизводимо и разъедется между EN и RU на второй же правке.

Поэтому `build/` — это не мусор сборки, а единственный способ отчёт пересобрать:

- `build.py` и `extract.py` — сам генератор;
- `payload.json` — структурированные находки, из которых рендерятся обе страницы;
- `figures.json` — данные схем;
- `terms.json` — словарь сложных терминов (мандат владельца прямо требовал объяснять термины
  простым языком, и это тот механизм, которым требование выполнено);
- `i18n/` — 13 файлов словарей перевода, разбитых по разделам.

Соседний `evidence/report-payload.json` (задача GSL-245) — тот же payload в доказательной базе.
Дубль намеренный: в `evidence/` он лежит как свидетельство, в `build/` — как рабочий вход
генератора. Расхождение между ними означало бы ошибку сборки.

## Как проверялось, что отчёт открывается

«Страницы готовы» — заявление, которое надо проверять, а не принимать на слово. Обе страницы
открывались в headless-браузере из `file://` и опрашивались скриптом:

- **CSS и JS реально загрузились** — не просто присутствуют в разметке, а `document.styleSheets`
  содержит `styles.css`, и `window.ARC_I18N` определён.
- **Фильтр находок живой** — счётчик отвечает: `99 / 99 shown` на английской, `99 / 99 показано`
  на русской. Это же подтвердило, что находок ровно 99 на обеих и что локализация доехала до
  динамических строк, а не только до статики.
- **461 внутренняя ссылка на каждой странице резолвится** в существующий якорь. Проверено
  дважды — статически (разбор HTML на 166 уникальных `id`) и в живом DOM через
  `document.getElementById`. Битых нет ни одной.
- **Перекрёстные ссылки EN↔RU рабочие**: `ru/index.html` с английской, `../index.html` с русской.
- **Обращений к внешней сети — ноль.** Ни CDN, ни шрифта, ни картинки по HTTP. Отчёт открывается
  с диска без интернета, что для документа, который будут читать через полгода, важнее красоты.

## Ловушка, на которую чуть не попались

В консоли обеих страниц есть одна строка `[error]`:

> Unsafe attempt to load URL file://…/index.html from frame with URL file://…/index.html.
> 'file:' URLs are treated as unique security origins.

Выглядит как дефект. Не дефект. Это Chrome ругается на сам протокол `file:` при навигации,
сообщение самоссылочное (страница «грузит» саму себя) и одинаковое на обеих версиях. В коде нет
ни `fetch`, ни `XMLHttpRequest`, ни `<iframe>`, ни динамического `import` — единственное обращение
к адресу во всём `app.js` это чтение `location.hash` для скроллспая. Проверено грепом, прежде чем
списывать сообщение как безобидное.

Записано здесь, чтобы следующий агент, открывший консоль, не начал чинить то, что не сломано.

## Что осталось

Ничего по этой задаче. Отчёт в git, воспроизводим, открывается офлайн.

Дальше по эпику: доказательная база под ним синхронизируется (GSL-245) — на момент этого коммита
`evidence/` ещё отставал от источника.

