# GSL-122 — Timeline: «that half of the log» → вычисленная доля hook-событий

Задача эпика GSL-141 «Fix wave 1: verification run 01 findings» (GH #138).
Jira: GSL-122 · GH: #140 · находка 10 аудита verifier-2026-07-20, run 01: NOT-LANDED.

---

## Часть 1 — человеческим языком

### Что сделано

Подпись под таблицей провенанса на Timeline говорила «that half of the log cost 0 tokens…»
о доле, которая по факту 92.8% (919 hook-событий из 990 на момент аудита). Слово «half» имеет
числовое значение, и оно занижало собственный результат почти вдвое — под той самой таблицей,
по которой читатель может это проверить.

Теперь подпись печатает **вычисленную долю**: `that {round(mechanical_share*100)}% of the log` —
из того же поля bundle (`events.mechanical_share`), которое Overview показывает как KPI
«N% mechanical», с тем же округлением. Проза и цифры больше не могут разъехаться: у них один
источник.

### Решённые проблемы

- **Выбор источника числа.** Считать долю заново в view (по `by_src`) — значит завести вторую
  формулу рядом с существующей; взято готовое `mechanical_share` из `build_status` (одно
  определение «механического» на весь проект: `src` начинается с `hook:`).

### Оставшиеся проблемы

- Нет. Закоммиченные страницы `docs/lab/site/*` пересобираются позже в этой же волне
  (коммит GSL-123) — до пересборки построенный `timeline.html` ещё несёт старую фразу.

### Подводные камни

- Фикстура T4 в smoke держала ровно одно событие (`emit`) — доля была бы 0%, и ассерт
  «печатается вычисленная доля» был бы вырожденным. Фикстура обогащена до 5 событий
  (3 hook + 1 emit + 1 poll-fill = 60%): доля нетривиальна и заведомо не «half».
  Попутно в фикстуру заложен tracker-poll 8-дневной давности — он включает staleness-баннер
  Tasks для следующей задачи волны (GSL-132, «polled … ago»).

### Что не вошло

- Переформулировка соседних предложений карточки — не тронуты (задача только про «half»).

## Часть 2 — техническая справка

### Файлы

- `tools/lab/ui/src/screens/timeline.tsx` — карточка провенанса: `that {Math.round(
  b.events.mechanical_share * 100)}% of the log`, несущий комментарий GSL-122.
- `tools/lab/smoke.sh` — фикстура T4: 5 событий вместо 1 (60% mechanical); новый блок
  GSL-122: ⭐ (нет «that half of the log», есть «that 60% of the log») + контроль (хвост
  предложения «cost 0 tokens and needed no model» цел).

### Как проверено прогоном

- **Красный прогон** ⭐ против родительской версии (`git show HEAD:…/timeline.tsx` до фикса):
  `FAIL: GSL-122 ⭐ … still calls the hook share 'that half of the log'`, контроль зелёный;
  RESULT PASS=359 FAIL=1 — ассерт ловит именно свой дефект.
- **Зелёный прогон** с фиксом: PASS=360 FAIL=0; `npx tsc --noEmit` — 0 ошибок.
- Фраза прочитана вслух по построенной фикстурной странице: «that 60% of the log cost
  0 tokens and needed no model's cooperation» — читается однозначно.
