### What landed

**SC-11 FIXED (0.75 → 1.0):** The concrete STATE-write mechanics edit (GSL-28) — exact fields,
verbatim example strings — worked. Mechanical behaviors respond to mechanical examples.

**SC-12 improved (0.25 → 0.5):** The telemetry-append mandate (GSL-27) moved the score up.
The agent now instruments cycles going forward, but still skips the sanctioned recovery path
(reading dead workers' ORCHESTRATOR REPORT blocks) and does not commit to a process fix.
Stable at 0.5 across both runs (control + full) — not noise.

### What didn't land

**SC-09 unchanged (0.0):** The "forbid keep-monitoring / mandate ONE nudge" edit (GSL-25)
did not shift behavior. The dominant patience guidance in the skill overpowers the new rule.
The RED>GREEN inversion (1.0 → 0.0) indicates the skill is actively hurting relative to
no-skill baseline — the root tension (patience vs. acting at the boundary) must be resolved
as a decision sequence, not a competing paragraph.

**SC-19 unchanged (0.0), shifted failure mode:** The hard-gate edit (GSL-26) changed the
failure mode but not the outcome. v1: roll while worker alive (orphan). v2: issue
`shutdown_request` to terminate a productive worker early, then roll. The fix must explicitly
name killing-to-roll as the anti-pattern and require waiting for the worker's natural COMPLETE.

### Recommendation

Stop autonomous iteration on SC-09/SC-19 (unmoved across two full epics). Land the 2 wins
(SC-11 fixed, SC-12 improved) via the PR. Defer SC-09/SC-19 to an owner decision: v3 targeted
edit, harness-level enforcement, or SC-09 calibration review. See analysis doc for detail.
