## Где мы прямо сейчас
🔄 Прогнали скилл против корпуса. Главное доказано: **скилл реально меняет поведение агента** (на сценарии
«преждевременный kill» без скилла агенты ошибаются, со скиллом — нет). Нашли **одну реальную дыру** (SC-03,
восстановление оркестратора) — её чиним следующей (TLM-64).
