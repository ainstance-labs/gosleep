# 02 — Завели проект harness

**Jira:** TLM-60 · **Статус:** ✅ готово · **Дата:** 2026-06-08

## Какую проблему решаем
Скилл жил только в `~/.claude/skills/` (вне гита). Чтобы развивать его как настоящий продукт (с тестами,
историей, потом — отдельным репозиторием), нужен git-трекаемый проект-источник.

## Что сделали
- Создали структуру **`docs/orchestration-harness/`**: `skill/` (источник), `evals/` (тесты),
  `design/` (дизайн web-версии), `README.md`.
- Написали **`install.sh`** — синхронизирует `skill/` в активную папку `~/.claude/skills/...`
  (источник правды в репо, но скилл остаётся включённым). Проверили — работает.

## Где мы
Есть аккуратный изолированный проект, готовый к выносу в отдельный репозиторий позже. Не мешает сборке
основного приложения (лежит в `docs/`).
