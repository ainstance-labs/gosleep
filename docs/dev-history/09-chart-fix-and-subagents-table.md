# 09 — Фикс графиков (freeze) + таблица всех 635 субагентов

**Jira:** TLM-68 · **Статус:** ✅ готово · **Дата:** 2026-06-09

## Какую проблему решаем
На страницах `runs`, `architecture`, `glossary`, `dev-history` графики «разъезжались», а страницы
жутко тормозили/висли. Плюс не было запрошенной таблицы со всеми субагентами.

## Что было не так (причина)
Классический баг Chart.js: графики с `responsive:true` + `maintainAspectRatio:false`, а у контейнера
`.chart-wrap` **не задана высота**. Canvas тянется под высоту родителя, родитель растёт под canvas →
бесконечный цикl resize/reflow → страница виснет, canvas «разъезжается». Рабочие страницы (index,
scenarios) этого флага не ставили, поэтому держались.

## Что сделали
- **Глобальный фикс в `report/assets/style.css`:** `.chart-wrap` → `position:relative; height:320px;
  overflow:hidden`, canvas позиционируется абсолютно внутри (фиксированный бокс рвёт цикл), плюс
  страховка `canvas { max-height:300px !important }`. Один файл — чинит все страницы разом, без
  перегенерации.
- **Новая страница `report/subagents.html`** — таблица **всех 635 субагентов**: детерминированно
  развёрнуто по структуре каждого прогона (прогон → роль → инстанс), сумма ровно 635. Есть сводка по
  прогонам + полный список с цветными бейджами ролей. Ссылка добавлена в навигацию на всех 9 страницах.
