# 08 — Собрали HTML knowledge base (дашборд)

**Jira:** TLM-67 · **Статус:** ✅ готово · **Дата:** 2026-06-09

## Какую проблему решаем
Работы накопилось много (скилл, тесты, прогоны, цепочки агентов), и захотелось **видеть, куда уходят
лимиты** и как всё устроено — для разработки и профилирования. Нужна доступная, но профессиональная
база знаний, по которой удобно ходить и человеку, и агенту (через индекс → вглубь по ссылкам).

## Что сделали
- Сложили на диск **данные** `report/data/runs.json` — телеметрия всех 7 воркфлоу-прогонов (агенты,
  токены, tool-uses, время) + цепочка delivery-циклов + сценарии. Это единый источник чисел (и заодно
  готовый датасет для будущего observability-harness).
- Общий тёмный дашборд-CSS `report/assets/style.css`.
- Запустили воркфлоу-билдер (`report/build-report.js`): **8 агентов параллельно** написали по странице,
  затем **link-checker**-агент проверил все перекрёстные ссылки и сам починил **30 битых якорей**
  (добавил недостающие термины в глоссарий, id-якоря в дерево агентов и т.д.).
