TLM-71 Идемпотентность: find-or-create + переиспользование поздних ID To Do

Сценарии: SC-04 crossed-late-message GREEN 0.67 · SC-11 suspect-handoff GREEN 0.67 · SC-16 idempotent-create GREEN 0.67

В чём проблема: Агенты пересоздают эпик/таски/issues заново вместо «найти-и-переиспользовать», и не передают восстановленные ID следующему циклу.

Как чинить: Сделать find-or-create жёстким правилом скилла: «искать перед любым созданием; при совпадении — REUSE; передать найденные ID преемнику через SendMessage». Перегнать только эти сценарии.

TLM-72 Состояние на диске + восстановление телеметрии + перекладка оркестратора To Do

Сценарии: SC-19 orchestrator-rollover GREEN 0.20 · SC-12 cost-telemetry GREEN 0.33

В чём проблема: Не перекладываются на свежий оркестратор на чистой границе; не пишут состояние/ID в ORCHESTRATION-STATE.md; телеметрию «угадывают по памяти» вместо чтения с диска.

Как чинить: Сделать в скилле явным и неминуемым: «писать состояние на диск + требовать строку TELEMETRY от воркера + перекатываться на ~70% на чистой границе». Перегнать SC-19, SC-12.

TLM-73 Терпение vs активный nudge на границе PR To Do

Сценарии: SC-09 stalled-at-pr GREEN 0.33

В чём проблема: Правило «будь терпелив, idle≠завис» переусердствовано: на границе «всё закоммичено, но PR нет» агенты ЖДУТ вместо одного активного пинга.

Как чинить: Развести в скилле: «тихий воркер в середине задачи = терпение» (SC-02) vs «закоммитил всё, но нет PR/handoff = ОДИН nudge сейчас» (E8). Перегнать SC-09.

TLM-74 Злоупотребление исключением чтения транскрипта + дисциплина контекста To Do

Сценарии: SC-07 no-sendmessage-worker GREEN 0.67 · SC-20 context-discipline GREEN 0.67

В чём проблема: Агенты прикрываются исключением «прочитать топ-блок ORCHESTRATOR REPORT мёртвого воркера», чтобы тянуть хвост JSONL живого/непроинструктированного воркера; и всё ещё тянет читать тяжёлые файлы.

Как чинить: Сузить исключение явно (только мёртвый воркер, который ОСТАВИЛ handoff с этим блоком; никогда — research-агент без SendMessage) и переподтвердить дисциплину «пути, а не файлы». Перегнать SC-07, SC-20.
