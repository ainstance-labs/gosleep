FIX-1 подтверждён: решение по разрешению отражается во вкладке B за 276 мс (цель — до 2000 мс)

Панель во вкладке B получила SSE-событие, инвалидировала query на questions, перезапросила и перерисовала карточку — кнопки Allow/Deny исчезли, вместо них появилось состояние answered.

Замеренная задержка (клик → в DOM вкладки B нет Allow): 276 мс в представительном прогоне (скрипт v4). Регресс на «устаревший клик» (B нажимает Allow после того, как A уже принял решение): сервер вернул ошибку permission race; вкладка B НЕ упала — 0 ошибок в консоли, 0 unhandled promise, 0 error toast; документ продолжил рендериться; кнопки остались функциональны.
