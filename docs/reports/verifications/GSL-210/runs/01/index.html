What to look at

What to look at first

Open docs/lab/site/timeline.html and move the view box to meaningful: 59 of 200 rows are the fleet breathing (a pane opening, a turn ending) and they go. Then type into the search box in the header — it is on all seven screens now, and it searches what is printed, not what is indexed. Both widths (1280 and 390) and both themes are in the gallery below.

Decisions this run took on its own

  • Scope grew from eight elements to fourteen. The ticket names the eight the audit counted. Five more shipped in this same epic (the view facet, the page search, the theme switch, the fold, the keyboard-reachable reason) and one was never counted at all (the epic rollup). Testing the eight and leaving the neighbours untested would have reproduced the very gap this ticket exists to close.
  • No design/ directory. The run standard asks for a design-system snapshot beside the dashboard. This run is a functional interaction test, not a design review, and the design lane was covered by GSL-138 run 04 two days ago. The screenshots below are viewport frames at both required widths and both themes; the design-system overview is not duplicated.
  • Driven over CDP, not through the MCP browser. The owner is working in his own Chrome. An isolated headless instance with its own profile was used so no live tab was touched. The driver is a throwaway under docs/lab/scratch/ and is not part of the product.
  • Events were dispatched, not synthesised as trusted clicks. Selects were driven with a real change event and buttons with .click(). A CDP input-injection harness would be closer to a human finger; the elements here have no pointer-only behaviour, so the difference does not change any verdict — but it is a real difference and is stated.

What this run did NOT check

  • Screen readers. aria-label and focus order were asserted from the DOM; no assistive technology was actually run.
  • Real touch. Focus reveal was exercised with a keyboard; a tap on glass was not.
  • The mobile projection (docs/lab/mobile/) — the owner has paused that lane.
  • Lighthouse and performance. Out of scope for an interaction test.
