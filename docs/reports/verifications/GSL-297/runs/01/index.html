4. Bugs uncovered + fixed inside GSL-297

GSL-298 · apps/core/scripts/snapshot.sh

Bug: prune_keep_last's empty-pipe case leaked exit 1 through set -o pipefail — the first snapshot on a fresh install returned rc=1 even though the .backup itself succeeded.

Fix: || true on the while pipe + explicit exit 0 at the tail, matching the header's "Retention failures WARN and continue" contract.

GSL-301 · apps/core/src/routes/internal.ts (flushPendingObservations)

Bug: Bun's Database.query(...).get(...) returns null (NOT undefined) when no row matches. The branch selector was written as if (existing !== undefined) UPDATE else INSERT — a null result satisfies !== undefined, so every fresh session_id took UPDATE, matched zero rows, and silently dropped the observation. First-time observations never landed.

Fix: existing !== null && existing !== undefined + removed the surrounding db.raw.transaction(() => …) wrapper + per-row try/catch that logs core.tool_observed.flush_error. Regression fenced by core-smoke scenario 25b.
