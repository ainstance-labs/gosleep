Заметки по архитектуре

Схема runtime-toggle — compound-OR gate shim + writes в реестр

The runtime side of the OR gate lives in tools/hooks/control-gate.sh. On every AskUserQuestion / PermissionRequest, the gate reads session_control[sid] via GET /internal/sessions/:sid/control (cached 1 s in $TMPDIR/gosleep-control-cache-<uid>/<sid>), and either enters the long-poll (controlled) or exits fast (observer). The panel writes come through POST /actions/sessions/:sid/take-control and /release-control, both wrapped in the three-layer envelope (requireBearer → serialize("session.control", sid) → withTimeline). On the fail-open guard: core-unreachable falls back to env-flag-only per the binding decision — never fail-open into interception.
