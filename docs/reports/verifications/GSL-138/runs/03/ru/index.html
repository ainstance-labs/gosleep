2 GSL-157 MAJOR Метр Freshness (Overview) functionality NOT-LANDED

Метр Freshness кодирует grade=dead как unknown-состояние

selfhealth.tsx:47 проецирует грейд данных тернарником без ветки dead: fresh → ok, stale → gaps, всё остальное → unknown. На закоммиченном билде (возраст данных 8h 17m > порога dead 3h) страница показывает красный DEAD-баннер сверху — а двумя блоками ниже карточка Freshness носит card sh-m unknown, магентовое «не могу прочитать показание».

Показание ПРОЧИТАНО: 8h 17m известен, вердикт dead вычислен. «dead» и «unknown» — центральная семантическая ось проекта (спека 4.3, урок GSL-109, докстринг компонента Unknown), и карточка кодирует известно-плохое состояние как нечитаемое — в успокаивающую сторону. В METER_CLASS вообще нет входа dead; meterClass выдаёт dead только для alarm handoff-метра, так что красное оформление .sh-m.dead для Freshness недостижимо.

4 GSL-159 MINOR Runway (Overview) design NOT-LANDED

Бейдж runway-bind в состоянии clear полуокрашен: ok-чернила поверх нейтральной формы

При r.bound === "clear" runway рендерит <span class="runway-bind ok">nothing is going to stop the night</span>. .runway-bind задаёт нейтральную тройку (мягкий фон, нейтральная граница, нейтральные чернила); span.ok (специфичность 0,1,1) перебивает только цвет. Итог — зелёный текст на нейтральной форме: гибрид, не соответствующий ни форме бейджа 7.1 (одна роль = одна тройка bg/ink/border), ни 8.1 («бейдж рядом со значением несёт грейд»). Сам theme.ts определяет span.ok для «inline-спанов внутри предложения», явно не для бейджей.

ЛАТЕНТНО: закоммиченный bundle — bound=unknown, состояние сегодня не видно; скриншот показывает ту же форму в текущем нейтральном состоянии. clear — целевое хорошее состояние дашборда, достижимое в любую здоровую ночь.
