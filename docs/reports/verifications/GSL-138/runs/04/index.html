5 GSL-168 MINOR Accessibility semantics design

Pages ship no document language (WCAG 3.1.1) and no th scope on 13 data tables (WCAG 1.3.1)

renderPage() emits <!doctype html><meta charset="utf-8">… with no <html> open tag at all (page.tsx:57-66), so the browser synthesizes an html element without lang — grep -c '<html' docs/lab/site/index.html → 0 on every page. WCAG 2.x SC 3.1.1 (Language of Page, Level A) requires the default human language to be programmatically determinable.

None of the 13 data tables sets scope on its th cells, and header rows are plain <tr><th> without thead. For simple single-header tables AT usually copes, but scope="col" is the baseline association mechanism (SC 1.3.1 / H63), and the widest tables here have 7-8 columns.

Both fixes are attribute-only — no new visible text (spec 1.1 intact), and none of the smoke-asserted attribute orderings involves th or a root html tag; the «first attribute-less script» stands (smoke.sh:1395/1576/1767) should be re-run in the same task. Norm layer: INDUSTRY-STANDARD; severity MINOR for a single-known-user internal dashboard, but formally a Level A criterion is unmet.
