3 GSL-148 MINOR Library, заголовки Reports functionality

Library видимо печатает «&amp;» в двух заголовках отчётов — двойной эскейпинг между chronicler и preact

Опции severity-фильтра идут в порядке появления (info, warn, incident) — не worst-first, как обещает сам код

Заметки по архитектуре и чистые проверки

Проверено чисто: схема-гард gosleep.lab.render/7, smoke-ассертируемые id/классы/data-* включая порядок атрибутов, без зебры, без теней, максимальный вес 500, без пунктирных рамок, tabular-nums на каждом тикающем числе.
