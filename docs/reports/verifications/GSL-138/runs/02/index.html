1 GSL-146 MAJOR Fleet + Cost, unknown values design

unknown values render as 11px muted labels — the label-span cascade swallows span.unknown

On Fleet, three of four KPI tiles (live workers, free slots, cycle) and the model / pane / started fields of all 8 worker cards carry the value unknown; on Cost, the ceiling and of-ceiling-used tiles do. The label selectors .kpi span and .wk-f span (specificity 0,1,1) also match the span.unknown the Unknown component renders, so the VALUE is painted as a LABEL: 11px, uppercase, display:block, weight 500 — and its colour resolves to --muted #68696b because .unknown (0,1,0) loses the cascade. A tile whose value is unknown reads as a card with two captions and no value, and the absence marker loses the --unk hue the design system reserves for "cannot read". Measured: .kpi b .unknown = 11px / uppercase / rgb(104,105,107); the sibling numeric value = 28px.
