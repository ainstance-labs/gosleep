Что это

Приёмочный отчёт рядом проверяет утверждения; эта страница показывает дизайн. Это визуальный обзор редизайна Laboratory UI (эпик GSL-111, референсный стиль: Mastra Studio / Supabase): система токенов с живыми образцами, ключевые компоненты, отрисованные вживую в обеих темах, и все семь экранов с кадрами первого вьюпорта.

pages/ — замороженный снапшот docs/lab/site/*.html на момент рана 01 (main @ fed234e, 2026-07-23). Каждая страница полностью самодостаточна — инлайновые CSS и JS, без внешних ресурсов — поэтому снапшот открывается из file:// ровно так же, как живой сайт. Все кадры ниже — строго первый вьюпорт (1280 × 800 и 390 × 844, DPR 1, светлая и тёмная темы), сняты с этого самого снапшота — никаких полотен на всю страницу.

Дизайн-система

Палитра — обе темы, вживую

Одна палитра, объявленная один раз: четыре уровня поверхностей и шесть статусных оттенков. Индекс поверхности означает роль, а не светлоту: в светлой теме «raised» темнее карточки, потому что ярче белого ничего не бывает. Каждый статусный цвет — тройка: чернила, мягкая заливка, рамка; ниже она показана живым чипом на собственной заливке.

Типографическая шкала

Системный стек шрифтов; моноширинный — для чисел, ключей и путей. База интерфейса — 13 px (--t-md, шаг text-ui-smd из Mastra для плотных инструментов); проза поднимается вверх до 14 px — и только она. Максимальный вес шрифта во всей системе — 500: иерархию несут размер и цвет, а не жирность.

Ключевые компоненты — вживую, не скриншотами

Отрисованы прямо здесь, значениями отгруженного CSS. Табы, не пилюли — активный пункт отмечен плотностью фона, а не акцентом (синий означает «ссылка», и страница, на которой вы уже находитесь, не должна читаться как самая важная ссылка на ней). Баннер свежести — контракт честности каждой страницы; статусные теги несут семантическую палитру.

Семь экранов

Каждый кадр — только первый вьюпорт: 1280 × 800 и 390 × 844 при DPR 1, обе темы, сняты вживую со снапшота в pages/ через file://. Клик по кадру открывает полный размер; стрелки листают четыре кадра страницы. «Открыть снапшот» — замороженная копия рана 01; «Открыть живую страницу» — текущий docs/lab/site/ вашего чекаута, который мог уйти вперёд после рана.

Overview — index.html

Главный экран: баннер свежести с тикающим возрастом, блок runway с шестью стоп-часами, карточки self-health, ряд KPI и состояние доставки.

Открыть снапшот → Открыть живую страницу ↗

Timeline — timeline.html

Полный журнал событий лаборатории по дням с семантической подкраской строк по важности. Обе сводные таблицы скроллятся внутри своего wrap на 390 px.

Открыть снапшот → Открыть живую страницу ↗

Tasks — tasks.html

Доска доставки: эпики и задачи с коммитами и dev history, читаемыми вживую из репозитория; устарелость трекера раскрыта честно, чипы эпиков различают ok/warn, ссылки на PR — по одной.

Открыть снапшот → Открыть живую страницу ↗

Questions — questions.html

Очередь вопросов в четырёх корзинах — открытые, отвеченные, истёкшие и «Decided by you» — чтобы ночь автономных решений оставалась проверяемой утром.

Открыть снапшот → Открыть живую страницу ↗

Fleet — fleet.html

Панели воркеров и их жизненные циклы; над карточками — мост сверки, «молчит — не значит мёртв», отделяющий известное от просто неуслышанного.

Открыть снапшот → Открыть живую страницу ↗

Cost — cost.html

Учёт токенов и стоимости по циклам — «Per cycle — 66» равно числу строк, а непокрытый отрезок раскрыт прозой, а не спрятан.

Открыть снапшот → Открыть живую страницу ↗

Library — library.html

Полки: хэндоффы, dev history, дайджесты и решения с настоящими счётчиками файлов (Handoffs 46, Dev history 93) и заголовками, сохраняемыми целиком до 158 символов.

Открыть снапшот → Открыть живую страницу ↗
