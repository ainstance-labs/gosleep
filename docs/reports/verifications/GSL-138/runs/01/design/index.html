What this is

The acceptance report next door verifies claims; this page shows the design. It is a visual overview of the Laboratory UI redesign (epic GSL-111, reference style: Mastra Studio / Supabase): the token system with live samples, the key components rendered live in both themes, and every one of the seven screens with first-viewport frames.

pages/ is a frozen snapshot of docs/lab/site/*.html as of run 01 (main @ fed234e, 2026-07-23). Each page is fully self-contained — inline CSS and JS, no external resources — so the snapshot opens from file:// exactly as the live site does. All frames below are strict first-viewport screenshots (1280 × 800 and 390 × 844, DPR 1, light and dark), taken from this very snapshot — no full-page canvases.

Design system

Palette — both themes, live

One palette, declared once, four surface levels and six status hues. Surface index means role, not lightness: in the light theme «raised» is darker than the card, because nothing can be brighter than white. Every status color is a triple — ink, soft wash, border — shown below as a live chip on its own wash.

Type scale

System font stack; monospace for numbers, keys and paths. The interface base is 13 px (--t-md, Mastra's text-ui-smd step for dense tooling); prose steps up to 14 px and is the only thing that does. Maximum font weight anywhere in the system is 500 — hierarchy is carried by size and color, not by bold.

--t-sm · .75rem / 12pxMono blocks, secondary meta.
--t-xs · .6875rem / 11pxTags, column headers, KPI labels.

Spacing and radii

Four scales declared once — nothing below them may invent a value outside the scale. That constraint is the product: a number that has to come from a scale cannot drift.

Key components — live, not screenshots

Rendered right here with the shipped CSS values. Tabs, not pills — the active item is marked by density of background, never by accent (blue means «link», and the page you are on must not read as the most important link on it). The freshness banner is the honesty contract of every page; status tags carry the semantic palette.
