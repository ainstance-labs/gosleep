## 5. Комментарии и свежие решения

- **Задача 4 из PRD не помещалась в один коммит** — PRD складывает в неё пять экранов сразу, а у нас
  инвариант «один коммит на задачу». Разделена на три (GSL-96 / GSL-97 / GSL-98). GSL-96 (Tasks)
  вынесен отдельно не по объёму, а потому что у него собственный критерий приёмки — F5-S3.
- **Граница Python/TypeScript зафиксирована явно, а не оставлена имплементатору.** `chronicler.py`
  остаётся **слоем данных**; `build_index` / `build_timeline` / `build_library` **удаляются**, их
  работу перенимает единый TS-рендерер на все 7 экранов, который `chronicler.sh` вызывает шагом
  рендера. Два рендерера в одном проекте = гарантированный дрейф разметки между «старыми» и «новыми»
  страницами. Поэтому переезд, а не сосуществование.
- **Архитектуру продиктовало `file://`, а не мода.** Страницы обязаны открываться с диска, где
  `fetch()` локального JSON запрещён CORS → данные **вшиваются в HTML на build-time**. Это статический
  генератор, не SPA, и это сужает выбор сильнее любых вкусов.
- **R4.2 закрыт — но «вне CLI» оказалось дырявым прокси, и это записано как находка.** Доказательство
  настоящее: `seq 156` в `docs/lab/events/2026-07-13.jsonl` @ `7b229c7` — единственная `vcs.pr.merged`
  во всём логе, `src="poll-fill"`, хуковой записи нет. Мёрж #102 **не увидел ни один хук**, и в таймлайн
  он доехал **сверкой**: механизм, ради которого poll-fill писался, отработал на живом событии.
  **Оговорка:** мёрж сделан через `gh api -X PUT`, а не из веба, как предписывал handoff 27. `gh` — это
  **и есть** CLI, значит **буква** критерия не выполнена; выполнено **свойство**, которое она обозначала
  (матчер `VERBS` знает только `gh pr merge` и про `gh api` не знает ничего — распознать такой мёрж хук
  физически не мог; а poll-fill к способу мёржа безразличен). Формулировку R4.2 задним числом **не**
  переписывал: подгонять критерий под полученное доказательство — ровно тот жанр, за который цикл 50 его
  и понизил.
- **Правка «на один значок» чуть не сломала пять цифр.** Таблица приёмки цитирует счётчики по логу, а
  леджер-коммит лог **дополнил**. Между `63b1c63` и `7b229c7` поехало **всё**: коммиты 11+3 → 12+4,
  Jira-переходы 9 → 11, панели 7/7 → 9/9, hook-строки 162 → 246. Перещёлкнуть только `merged: 0 → 1`
  означало бы оставить остальные тихо неверными на новом sha — дефект M2/M4, который цикл 50 и чинил.
  Теперь jq-рецепт даёт **две колонки** с явной привязкой к sha. Компакция на обоих = 0, поэтому
  **F4-S1 честно остаётся 3 из 4**.
- **Сквозное требование, вписанное в каждую задачу: отсутствие данных показывается как отсутствие.**
  Час runway без источника — `unknown`, а не оптимистичная константа (иначе `min()` удлинится и
  соврёт про сон). Метр self-health без данных — `unknown`, а не зелёный. Ячейка Tasks без коммита —
  пустая, а не правдоподобная битая ссылка. Фильтр, что-то скрывший, показывает, сколько скрыл.
  Фаза 4 потратила целый цикл (50) на то, чтобы вычистить три способа, которыми лаборатория врала о
  себе. Фаза 5 строит **экран, по которому владелец решает, можно ли идти спать** — у него нет права
  завести четвёртый.

## Gotchas

- **Коммит с сообщением через heredoc хук не видит** (несбалансированные кавычки → парсер молчит).
  Используй `git commit -F <файл>`, если хочешь, чтобы коммит попал в лог механически. Этот цикл так и делал.
- **Возрастов два, а не один.** `grade` судит **данные** (`max_event_age_s`), а не **страницу**.
  Потребитель `status.json` обязан прибавить `now − generated_at` **до** того, как поверить `grade`.
  Страницы делают это сами при открытии. Новый TS-рендерер обязан унаследовать это, а не переоткрыть баг.
- **Цитаты-счётчики считать из индекса** (`git show :path`), а не из рабочего дерева: хук дописывает
  строку в лог во время самого коммита, поэтому закоммиченный файл — всегда префикс живого.
- **Один фантом в логе остаётся намеренно** (строка `seq 48` от 2026-07-13 несёт sha `5be2adc`) —
  оставлен ревьюером как воспроизведение дефекта C1; лог append-only, убрать нельзя. Правило чтения —
  в `docs/lab/events/README.md`.
- **`docs/prompts/` не коммитить никогда** — owner-sovereign.
